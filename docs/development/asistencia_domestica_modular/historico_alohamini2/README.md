# Resultados históricos de la plataforma anterior

Estos registros documentan las fases ejecutadas antes del cambio al AlohaMini1. Se mantienen las identidades de robot, métricas, hashes y rutas de origen que acreditan aquellas ejecuciones; no deben presentarse como ensayos del nuevo robot. Los JSON se conservaron sin cambiar sus resultados. En los Markdown se ajustaron enlaces que apuntaban a código retirado.

La implementación activa y sus comandos están en la [migración al AlohaMini1](/docs/development/asistencia_domestica_modular/migracion_alohamini1.md). Las fuentes anteriores se pueden consultar en el historial Git; el trabajo F4 aún no confirmado en Git tiene además copia local de respaldo en `.ignore.migration_alohamini1/alohamini2/`.
